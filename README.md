# Check My Bill for Home Assistant

Validates utility bills against the energy your own meters recorded. Check My Bill reads the
sources already configured on the Energy dashboard (grid import/export, gas, prices) and the
billing cycle reported by utility integrations such as Opower. It then shows usage and expected
cost for the current and previous billing cycles next to what the utility says.
